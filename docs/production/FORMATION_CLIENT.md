# Formation Client eNkamba

## Objectif de la formation

Former l'équipe client à utiliser eNkamba en conditions réelles : navigation, traitement des opérations, administration, support et procédures de contrôle.

## Public concerné

- Administrateurs.
- Agents support.
- Agents logistique.
- Agents business.
- Responsables financiers.
- Superviseurs opérationnels.

## Format conseillé

- Durée : 2 jours.
- Support : APK installée sur téléphones Android, accès web production, comptes de test.
- Méthode : démonstration, exercices guidés, cas pratiques et questions-réponses.

## Jour 1 - Utilisation opérationnelle

### Session 1 : Découverte de l'écosystème

Objectifs :

- Comprendre les apps eNkamba.
- Identifier le rôle de Paiement, Marché, Logistique, Chat, Social et Admin.
- Comprendre la navigation générale.

Exercice :

- Installer l'APK.
- Se connecter.
- Parcourir les apps principales.

### Session 2 : Logistique

Objectifs :

- Créer une demande de livraison.
- Rechercher une agence.
- Enregistrer un colis.
- Scanner un QR/code-barres.
- Suivre un colis.
- Lire une preuve de livraison.

Exercice :

- Créer un colis test.
- Changer son statut.
- Le retrouver dans l'interface Suivre.

### Session 3 : Marché

Objectifs :

- Rechercher un produit.
- Lire une fiche produit.
- Confirmer une commande.
- Accéder à l'itinéraire interne Ugavi.

Exercice :

- Simuler une commande.
- Vérifier la connexion entre Marché et Logistique.

### Session 4 : Chat et Social

Objectifs :

- Démarrer une conversation.
- Utiliser les catégories personnel/business.
- Accéder au profil public.
- Publier un média.
- Comprendre restriction et blocage.

Exercice :

- Envoyer un message.
- Modifier le fond de discussion.
- Tester la traduction d'un message.

## Jour 2 - Administration et exploitation

### Session 5 : Admin

Objectifs :

- Lire le dashboard admin.
- Ouvrir Infrastructure, Logs et Cyber.
- Identifier un incident.
- Copier et partager une erreur.

Exercice :

- Rechercher une erreur simulée.
- Rédiger une note d'incident.

### Session 6 : Paiement

Objectifs :

- Comprendre le portefeuille.
- Lire l'historique.
- Utiliser le QR paiement.
- Comprendre le masquage du solde.

Exercice :

- Vérifier une transaction test.
- Télécharger ou partager un reçu si disponible.

### Session 7 : Comptes business

Objectifs :

- Lire une demande business.
- Vérifier les documents.
- Comprendre les statuts agence.
- Utiliser le scoring de fiabilité.

Exercice :

- Traiter une agence nationale test.
- Passer son statut en vérification.

### Session 8 : Support et procédures

Objectifs :

- Savoir répondre à un client.
- Savoir remonter un bug.
- Savoir traiter un colis bloqué.
- Savoir protéger les données sensibles.

Exercice :

- Traiter un scénario : colis non livré, paiement en attente, compte bloqué.

## Résultat attendu

À la fin de la formation, l'équipe client doit pouvoir :

- Utiliser l'APK.
- Traiter les opérations principales.
- Superviser les erreurs.
- Gérer les demandes business.
- Suivre les colis.
- Orienter les utilisateurs.
- Escalader les incidents correctement.
